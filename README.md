# 🛡️ Cyber Forensics Investigation Platform

A web-based application that demonstrates digital forensic investigation workflows by integrating **Email Forensics**, **Image Forensics**, and **Network Forensics** into a single platform.

## 🚀 Live Demo

**Live Website:** https://cyber-forensics-platform.onrender.com

---

## 📖 Project Overview

The Cyber Forensics Investigation Platform is designed to simplify digital evidence analysis by providing multiple forensic modules in one application.

Users can upload their own evidence or use the built-in sample datasets to explore forensic investigation techniques through an interactive dashboard.

---

## ✨ Features

### 📧 Email Forensics

* Email Header Analysis
* SPF Verification
* DKIM Verification
* DMARC Verification
* Sender IP Analysis
* Risk Assessment

### 🖼️ Image Forensics

* EXIF Metadata Extraction
* GPS Metadata Detection
* SHA-256 Hash Generation
* Basic Steganography Detection

### 🌐 Network Forensics

* Network Log Analysis
* Suspicious Event Detection
* Timeline Visualization
* Investigation Summary
* Risk Assessment

### 📊 Dashboard

* Interactive Dashboard
* Investigation Summary
* Risk Indicators
* Centralized Results

---

## ⚙️ How It Works

1. Open the web application.
2. Select one of the forensic modules:

   * Email Forensics
   * Image Forensics
   * Network Forensics
3. Upload your own evidence or use the provided sample files.
4. The application analyzes the evidence.
5. View the investigation summary, timeline, and risk assessment.
